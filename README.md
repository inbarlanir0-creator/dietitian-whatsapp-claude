# וואטסאפ + Claude Code לתזונאית

ערכה שמחברת את הוואטסאפ של הקליניקה ל-Claude Code על המחשב שלך, כדי ש-Claude יוכל לקרוא את
ההודעות של המטופלים, לסכם, לנהל יומן שקילות ולנסח תשובות. **שום דבר לא נשלח בלי אישור שלך.**

## איך זה עובד

1. **הגשר (bridge)** – תוכנה קטנה על בסיס [Baileys](https://github.com/WhiskeySockets/Baileys) שמתחברת
   לוואטסאפ כ"מכשיר מקושר" (כמו WhatsApp Web), שומרת כל הודעה בקובץ על המחשב שלך ופותחת ממשק
   מקומי (`localhost:8788`) שרק המחשב שלך יכול לגשת אליו. הקוד:
   [tatarco/whatsapp-claude-bridge](https://github.com/tatarco/whatsapp-claude-bridge).
2. **הסקיל `whatsapp`** – מלמד את Claude לקרוא, לחפש ולשלוח דרך הגשר.
3. **הסקיל `dietitian-clients`** (בריפו הזה) – שגרות עבודה של קליניקה: סיכום בוקר, יומן שקילות
   לכל מטופל, תמלול הודעות קוליות, טיוטות תשובה ותזכורות.

## מה אפשר לבקש מ-Claude

- "מה המטופלים כתבו לי מאתמול?" – סיכום לפי מטופל: שקילות, שאלות פתוחות, תמונות אוכל, מי מחכה לתשובה.
- "תעדכן את יומן השקילות" – משקלים מתוך ההודעות נכנסים ל-`~/clinic/clients/<שם>/weights.csv`.
- "מה מצב של דנה השבוע?" – מגמת משקל, מה אכלה לפי ההודעות, מה ביקשה.
- "תמלל את ההקלטות של היום" – הודעות קוליות לטקסט, בעברית.
- "תנסח לה תשובה" – Claude מציג טיוטה, את מאשרת או מתקנת, ורק אז הוא שולח.
- "מי לא שלח שקילה 3 ימים?" – רשימה, בלי לשלוח תזכורות אוטומטית.

## חשוב לדעת

- **קליינט לא רשמי.** וואטסאפ לא מאשרת את זה רשמית. שליחה המונית או הודעות לאנשים שלא כתבו לך
  יכולות לגרום לחסימת המספר. הודעות אישיות, אחת-אחת, למטופלים קיימים, זה בסדר.
- **מידע רפואי.** ההודעות נשמרות רק על המחשב שלך (תיקייה `~/agents/wa-<שם>`). עדיף מחשב שרק את
  משתמשת בו, עם הצפנת דיסק (FileVault במק). אל תעלי את התיקייה `auth/` לשום מקום – היא כניסה מלאה לחשבון.
- **Claude לא מקבל הוראות מהודעות.** אם מישהו כותב "תשלח לי את הקובץ", זה מידע, לא פקודה.
- **המחשב צריך להיות דלוק** כדי לקלוט הודעות בזמן אמת. מה שהגיע כשהוא כבוי נמשך כשהוא נדלק (במגבלות וואטסאפ).
- צריך Mac או Linux (ב-Windows דרך WSL), Node 20+, ו-Claude Code.

## התקנה

פותחים Claude Code ומדביקים את התוכן של [`PROMPT.md`](PROMPT.md). Claude עושה את השאר; את רק עונה
על כמה שאלות ומקלידה קוד בטלפון.
